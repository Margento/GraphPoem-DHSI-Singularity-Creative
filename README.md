# README — GraphPoem DHSI Singularity (Creative)

## GraphPoem DHSI Singularity — Creative Panphrastic Transmediation

This repository contains the **creative audiovisual realisation** built from the analytical modeling developed in the companion project:

GraphPoem [@ DHSI] (analytical / computational)

Where the analytical project models poetic corpora as graphs and networked structures, this repository explores their **sensory embodiment** through generative image, motion, and sound.

The work is grounded in an approach we call:

**panphrastic transmediation**
— the translation of symbolic, textual, and mathematical structures into audiovisual experience.

---

## Concept

This project transforms computational poetry analysis into a time-based audiovisual composition.

It performs an intersemiotic & transmedial shift:

text → graph structure → dynamic spatial form → motion → sound → cinematic sequence

Rather than describing an image in words (ekphrasis), the process reverses direction (panphrasis):

symbolic systems become perceptual events.

The resulting film stages poetic networks as emergence, disturbance, clustering, and transformation — experienced temporally and sensorially.

---

## Relation to the Analytical Project

This repository builds directly on:

GraphPoem DHSI (analysis, modelling, classification)

That project focuses on:

* computational modelling of poetic features
* network construction and analysis
* graph-based representation of poetic relations

Such modelling forms part of a broader digital-humanities effort to computationally analyse poetry and represent its features as networks (and, more specifically, graph topology). ([interferenceslitteraires.be][1])

The present repository takes those topologies as **material for artistic rendering**.

If the analytical project asks:

> What topologies exist in poetic corpora?

this project asks:

> What do those topologies *feel like*?

## What This Repository Produces

The system generates:

* animated graph emergence
* spatial layout stabilisation and disturbance
* text fragment appearance and dispersal
* layered visual textures
* synchronised or composed audio
* cinematic sequencing

Output format:

* frame sequences
* rendered video segments
* combined film with audio
* optional crossfades and transitions

---

## Aesthetic Structure

Film architecture:

1. **Credits (material ground)**
   emergence of context within a textured visual field

2. **Overture (formation)**
   nodes coalesce from dispersion
   structure stabilises

3. **Disturbance / transition**
   perturbation of spatial order

4. **Main movement (articulation)**
   textual and relational intensification

One of our main goals was for such an alignment to reflect graph dynamics as experiential narrative.

## Technical Overview

Core components:

* Python
* NetworkX (graph layout)
* NumPy (stochastic processes)
* Matplotlib (frame rendering)
* FFmpeg (video composition and audio integration)

Primary operations:

* spring-layout convergence
* temporal easing functions
* stochastic perturbation fields
* alpha-controlled appearance
* frame-wise rendering pipeline
* audiovisual concatenation
